# Local microscopy images

Place your own microscopy image at `raw/steel_01.png`, or pass `--image` to the
inspection script. Raw images are ignored by Git. Use images only with appropriate
permission; no dataset is redistributed in this repository.

The Session 1 local example was downloaded from IIT Kanpur Virtual Labs:

- Reference: https://spm-iitk.vlabs.ac.in/exp/microstructure-various-steels/theory.html
- Figure 3(a), hypoeutectoid steel, captioned 500 X.
- Image: https://spm-iitk.vlabs.ac.in/exp/microstructure-various-steels/images/Picture1.jpg
- Accessed: 2026-11-07.

The downloaded JPEG is converted to PNG without resizing. The source page links
CC BY-NC-SA 4.0; consult its terms before reusing source material. The sample and
its generated plot stay local. Magnification alone does not establish a physical
pixel scale. Text and scale markings must be excluded from future segmentation.
